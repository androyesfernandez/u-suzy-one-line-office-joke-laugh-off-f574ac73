# One-Line Office Joke Laugh-Off

A single-line office joke entry for the make.fun micro competition "One-Line Office Joke Laugh-Off".

The joke:

> During the fire drill my manager marked me present, then asked me to finish the quarterly report on the sidewalk because the building was burning but the deadline wasn't.

## Run

```sh
node main.ts
```

This writes the joke to `/output/entry.txt` (170 characters, one line, no trailing newline).
